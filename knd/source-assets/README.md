# Исходники монтажа

`interfaces/` содержит реальные обезличенные вклейки и разворот книги помощника.
Файлы уже использовались в опубликованных роликах; личные данные закрыты на самих изображениях.

`raw-media/` — шесть чистых HD-генераций до вклейки интерфейсов: ЕРКНМ, схема,
три сценария МП «Инспектор» и ИИ-помощник. Это производственные файлы филина,
поэтому в публичном репозитории их нет: они лежат в приватном
`centnot/knd-presentation-sources` по пути `knd/source-assets/raw-media/`.
Неправильное содержимое экранов в этих исходниках намеренно заменяется скриптами.
Для показа использовать итоговые файлы `../media/`, а не сырой материал.

Старые готовые ролики, включая ЕРВК, находятся в корневой `media/` репозитория.
Референсы новых генераций — в приватном репозитории, `knd/server/refs/`. Веса моделей не включены в Git.
PPTX-шаблон и задание — в `../materials/`, извлечённое оформление — в `../template-assets/`.

`manifest.json` содержит размеры и SHA-256 исходных видео, интерфейсов и шаблонных ресурсов;
пути `source-assets/raw-media/...` относятся к папке `knd/` приватного репозитория.
Повторный монтаж: `python scripts/repair_video_interfaces.py` из каталога `knd/`, когда
приватный репозиторий склонирован рядом с checkout или задан `KND_PRIVATE_SOURCES`.
