# КНД — медиа-презентация Роструда

Рабочий проект для Форума контрольных органов — 2026. Сайт: https://centnot.github.io/vnot-presentation-v4/knd/.

**Для продолжения на другом компьютере сначала прочитать [HANDOFF.md](HANDOFF.md).**

В GitHub старая презентация находится в корне репозитория, новая — в `knd/`.
Обе версии сохранены. Коммиты новой версии затрагивают только `knd/`.

## Быстрый запуск из GitHub

```sh
git clone https://github.com/centnot/vnot-presentation-v4.git
cd vnot-presentation-v4
python -m http.server 8173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8173/knd/. Старая презентация доступна по http://127.0.0.1:8173/.
Для показа не нужны Node, Python-библиотеки или GPU: Python здесь только раздаёт статические файлы.

## Что редактировать

- `index.html`, `styles.css`, `app.js` — каркас, оформление и поведение сайта.
- `content.json` — порядок разделов, тексты, показатели, даты и пометки докладчику.
- `speech.txt` — автоматически собираемый текст выступления.
- `media/` — восемь опубликованных роликов и их первый/последний кадры.
- `assets/`, `template-assets/` — оформление из шаблона форума.
- `source-assets/` — чистые исходники для воспроизводимого монтажа.
- `scripts/` — подготовка сайта, ремонт интерфейсов, стабилизация и визуальная проверка.
- `materials/` — задание, фактическая сводка, запросы недостающих данных, QA-отчёт и PPTX-шаблон.
- `server/` — настройка и управление GPU-сервером, генератор и референсы. Локальную конфигурацию доступа создают отдельно.

При работе в исходной Windows-папке вместо checkout файлы сайта лежат в `site/`;
скрипты автоматически распознают оба расположения. В клоне GitHub редактировать
файлы непосредственно в `knd/`, без создания второй копии `site/`.

## Инструменты для монтажа и подготовки

Проверенное окружение: Python 3.12 и Node 24; FFmpeg/ffprobe должны быть в PATH.
Установить Python-зависимости из `requirements.txt` в локальное виртуальное окружение.

```sh
cd knd
python -m venv .venv
# Linux/macOS: source .venv/bin/activate
# PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python scripts/prepare_site.py
node --check app.js
node --test tests/playback-end.test.mjs
```

Полностью повторить монтаж из закоммиченных исходников:

```sh
python scripts/repair_video_interfaces.py
python scripts/prepare_site.py
python scripts/review_videos.py
```

Для отдельного первого ролика: `python scripts/repair_erknm.py`, затем подготовка сайта.
Результаты монтажа и контактные листы создаются в игнорируемом `build/`.
Windows использует Arial; Linux — DejaVu Sans или Liberation Sans; macOS — Arial.
Путь можно задать переменными `KND_FONT` и `KND_FONT_BOLD`.
Старые готовые ролики скрипты берут из корневой `media/` того же репозитория.
Поэтому клонировать нужно весь репозиторий, а не скачивать только папку `knd/`.

## Управление показом

Стрелки, PageUp/PageDown, пробел — переходы. Цифры 1–9 и 0 — разделы.
T — оглавление; N — текст; R — повтор ролика; P — пауза; F/F5 — полный экран;
B/точка — чёрный экран; Home/End — начало/финал.
У ЕРВК и инструкций есть два явно обозначенных экрана. Инструкции автоматически
открываются через 20 секунд активного показа; пауза и диалоги останавливают отсчёт.

После окончания ролика видимым остаётся его последний декодированный кадр.
Нельзя снова скрывать видео через `go(chapter, 1)` в `ended`: это возвращает мигание заставки.

## Публикация

Проверить изменения, выполнить тесты и отправить коммит в `main` того же репозитория.
GitHub Pages автоматически публикует `/knd/`. Сохранять старые файлы корневой презентации.
После изменения JS обновить параметр версии в `index.html` и в запросе `content.json`.
После изменения ролика обновить версии его `video`, `first`, `poster` в `content.json`.

Доступы к Selectel, SSH-ключи, локальные конфигурации, модельные веса и экспорт
рабочей переписки в репозиторий не входят. Их отсутствие не мешает сайту и CPU-монтажу.
